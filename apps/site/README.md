# @spotcraft/site

SvelteKit app (adapter-node): the public Spotcraft website and documentation.

Current state: a placeholder page. Styling and components come from
[`@spotcraft/ui`](../../packages/ui) (Tailwind v4, shadcn-svelte).

```sh
pnpm --filter @spotcraft/site build      # output in build/
pnpm --filter @spotcraft/site typecheck
```
